# 心理学保研 DDL

面向心理学专业学生的夏令营、预推免与推免接收截止日期聚合站点。产品形态参考 [CS-BAOYAN-DDL](https://github.com/CS-BAOYAN/CS-BAOYAN-DDL)，当前版本先完成可用的前端检索体验。

## 已实现

- 按届次/阶段切换数据源
- 学校、学院和研究方向搜索
- 院校类型、状态、培养类型、方向、地区组合筛选
- 本周、本月、全部时间范围
- 截止倒计时与报名状态判断
- 列表/月历双视图
- 项目详情、深浅色主题、键盘快捷键
- 筛选状态同步到 URL，便于收藏和分享

## 数据说明

当前 `lib/programs.ts` 内的记录全部是界面演示数据，不代表院校真实安排。正式收录时应至少核验学校或学院官网通知，并填写原始通知链接、截止时间精度与最近核验日期。
