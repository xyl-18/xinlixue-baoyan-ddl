## 判定

四项需求尚不能认定全部满足。当前库27条记录涉及24所学校、26个院级展示名称，其中6条校级通知。既有116个核验对象中只有22个已有部分记录（库中另外两校是深圳大学、中国科学院大学）。有一条通知不等于该校所有学院已覆盖。

| 需求 | 判定 |
| --- | --- |
| 全部985/211相关专业通知 | 未满足：多数对象仍待目录与通知核验，尚未建立完整院级分母 |
| 不重复、不遗漏关键预推免 | 未发现重复id或同校同院同类首轮；但关键院校和其他学院仍待核验，上海交大只有夏令营，不能算预推免覆盖 |
| 每条直达学院通知 | 未满足：复旦、北师大、南大、天津大学、苏州大学、西南大学仍用校级来源；中山公众号本次遇验证码。浙大已从心理系官网首页追溯到院系官方公众号入口 |
| 功能与参考站对齐 | 2027届核心功能、分享状态和移动端交互已验收；多年份数据仍缺，不能宣称完全对齐 |

“待核验”不等于“未发布”“不招生”或“已确定遗漏一份发布的通知”。本次是核对与修正，不是对全国数据完整性的认证。

已对116所学校逐校执行“学校名＋心理学＋2027＋推免＋接收”的第一轮检索，并追加包含附件主要专业代码的第二轮检索；查询结果分别保存到 `search-sweep-2026-09-05.json` 和 `code-search-sweep-2026-09-05.json`。两轮检索用于发现候选学院，不能替代逐校读取当年招生目录；搜索引擎未返回结果的学校仍保持待核验。
